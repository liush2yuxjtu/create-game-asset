# Templates

- DESIGN.md: eight prose areas, with scope and provenance linked to system.json.
- SCREEN.md: one screen's states, inputs, evidence and responsive behavior.
- FLOW.md: a user goal expressed as transitions between screen IDs.
- VERIFY.md: findings by evidence scope.
- system.json: small tracking format; not a DTCG or Google DESIGN.md schema.
- VFX_SPEC.json: optional game contract; unfilled values are explicitly unknown.

Scaffolder copies these into a new folder. Replace drafting instructions with evidence or proposals; running it alone is not extraction or verification.
