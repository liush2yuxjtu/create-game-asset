# Asset Pipeline Reference

## Canonical Flow

```
User Intent
    ↓
Asset Spec
    ↓
Reference Asset
    ↓
Animation / State Expansion
    ↓
QA
    ↓
Package
```

## Inspired Workflow

A Hatch Pet style pipeline separates:

- identity creation
- pose generation
- visual verification
- runtime packaging

This avoids identity drift between generated states.
