# 扩展路线（按对增长的杠杆排序）

## A. 视频 ⇄ 游戏闭环（增长引擎）
1. **玩家版分镜**：录屏模式读取玩家本世真实事件（谁背刺、带了哪条记忆、第几世），自动生成「我的第 N 世」分镜 JSON → 每个玩家都能产出不同的同款视频
2. **一键出片**：Web 端用 MediaRecorder 录 canvas + 音频，直接产出 9:16 mp4（省掉手动录屏）
3. **评论区即关卡**：视频 CTA 问「你会带哪条记忆」→ 高赞答案做成下周限定记忆卡
4. **A/B 钩子**：`viral_script.json` 多套 hook（死 99 次 / 师兄背刺 / 数字爆炸开场），按完播率选

## B. AI 角色深度
1. 多 NPC 社会：同门之间也用 OpenGameAgent 协议互相结盟/背刺，玩家只是其中一员
2. 记忆检索升级：NPC 记忆接入 OpenGameAgent.Memory 语义检索，替代现在的 importance×衰减排序
3. 长老夺舍线：长老的记忆也跨世，他会越来越针对「那个总能预判我的弟子」
4. 成本控制：只在波次开始/关键事件调用；quick 档；同一 GameInput 5 分钟缓存

## C. 数值与内容（一念逍遥 + Paperclips）
1. 三阶段 Paperclips 式转场：外门（手动）→ 执掌魔门（管理弟子 agent）→ 吞并正道（宗门级数值）
2. 功法/法宝/洞府三条挂机线；离线收益上限随洞府升级
3. 轮回树：道痕解锁「记忆槽」「开局境界」「NPC 初始好感」

## D. 平台
1. GitHub Pages / 抖音小游戏 / 微信小游戏（Godot Web 导出可直接托管）
2. 手机竖屏 PWA、震动反馈
3. 存档云同步（换设备不丢记忆——正好契合主题）
