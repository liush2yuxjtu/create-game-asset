# v2 扩展路线

## A. 新手引导 → 增长闭环（最高杠杆）

新手引导已经能 1:1 复刻爆款视频。往下扩：

1. **玩家版分镜**：引导结束后，用玩家这一世的真实事件（死在哪、铭刻了哪片、自由输入说了什么、师兄怎么回）自动拼一份 `viral_script` → 每个玩家都能录出「我的第 N 世」，而不是同一条视频。
2. **一键出片**：Web 端用 `canvas.captureStream()` + MediaRecorder 直接导出 9:16 视频（桌面端已可用 Movie Maker 录）。
3. **多套钩子 A/B**：`viral_script.json` 支持多份（死 99 次 / 师兄背刺 / 「我也死过99次」反转开场），按完播率挑。
4. **评论区即关卡**：CTA 问「你会带哪段记忆进下一世」→ 高赞回答做成限定碎片或限定回响。
5. **「挖层」挑战**：分享卡只显示 ■■□□，不剧透内容；朋友点进来直接进第一章，目标是比你多挖一层。

## B. 内容：层与碎片

1. 每章再加 1 层（上限 5）。新层优先用「回响」解锁（上一世第 N 章的选择改变下一世第 N-k 章），这是本作最独特的机制。
2. 碎片冲突：两片记忆互相矛盾（有一片是长老伪造的），玩家要判断铭刻哪一片。
3. 结局后「第 101 世」：保留全部碎片，开放第六章。

## C. AI 角色

1. 长老也跨世记忆：他会越来越针对「总能预判我的弟子」，逐世改变第三、五章的战术。
2. 同门之间用同一协议互相结盟/背刺，玩家只是其中一员。
3. 记忆检索接入 OpenGameAgent.Memory 语义检索，替代现在的 importance×衰减排序。
4. 成本：只在节点进入/自由输入/战斗开始调用；同一 GameInput 缓存。

## D. 平台

GitHub Pages（已接）→ 抖音/微信小游戏（Godot Web 导出）→ 竖屏 PWA、震动反馈 → 存档云同步（换设备不丢记忆，正契合主题）。
